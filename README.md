# CATL (300750) Financial & Stock Analysis

## 1. Problem & User
This project analyzes the financial performance and stock price trend of CATL (300750), the world's leading battery manufacturer. The target users are investors in the new energy industry, financial analysts, and students who want to understand the company's growth.

## 2. Data Source
- Database: WRDS CSMAR
- Financial data: wrds_csmar_financial_master (annual reports)
- Stock data: trd_mnth (monthly stock price)
- Retrieved on: 2026-04-14

## 3. Methodology
- Python + WRDS SQL for data extraction
- Pandas for data cleaning
- Matplotlib for visualization
- Export to Excel for presentation

## 4. Key Insights
- CATL's revenue and net profit grew rapidly from 2017 to 2025.
- Stock price fluctuated with industry policies and market demand.
- The company's asset expansion matched its industry leadership.

## 5. How to Run
1. Connect to WRDS
2. Run the notebook cell by cell
3. View charts and exported Excel files
