# CATL (300750) Financial & Stock Analysis

## 1. Problem & User
This project analyzes CATL (300750), the world's leading battery manufacturer.
Target users: new energy investors, financial analysts, and students studying energy industry stocks.

## 2. Data Source
- WRDS CSMAR
- Financial data: wrds_csmar_financial_master
- Stock data: trd_mnth
- Retrieved on: 2026-04-14

## 3. Methodology
- Python + WRDS SQL for data extraction
- Pandas for data cleaning
- Matplotlib for visualization
- Export to Excel

## 4. Key Insights
- CATL's revenue and net profit grew rapidly between 2017-2025.
- Stock price fluctuated with industry policies and market demand.
- Strong asset expansion matched its industry leadership.

## 5. How to Run
1. Connect to WRDS
2. Run the notebook
3. View charts and exported Excel
